## 功能概览

- 主界面仅做**脚本管理**：新建 / 复制 / 删除 / 加载脚本
- **编辑与运行全部在悬浮窗内完成**：脚本名称、运行方式（循环 / 次数 / 时长 / 间隔）、运行变量、步骤增删改排序、识图素材导入与删除
- **步骤可视化 + 拖拽调整落点**：点击 / 长按 / 滑动 / 多点滑动以彩色标记叠加显示，直接拖动即可改坐标，跨分辨率复用
- 识图 / 识文脚本运行前由悬浮窗发起屏幕采集授权
